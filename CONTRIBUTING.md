# Contributing

Thanks for helping make **Awesome Free AI** better. Contributions of all sizes are welcome.

## Adding a tool

1. Make sure the tool is **free or open-source** and **actively maintained** (recent commits in the last ~12 months).
2. Add it to the most fitting section, keeping entries sorted by star count (descending).
3. Use this format:

   ```markdown
   - **[owner/repo](https://github.com/owner/repo)** `⭐ 12k` — One clear sentence, no marketing speak.
   ```

4. Link to the **primary source** (GitHub repo, or the official site if it is not open-source).
5. Keep descriptions short, factual and free of superlatives.

## Removing or fixing

- Dead links, abandoned projects, or things that moved behind a paywall should be removed.
- If a project was renamed or moved, update the link.

## Pull requests

- One tool per PR where possible.
- Keep the diff focused — do not reformat unrelated lines.
- Describe *why* the tool belongs in the PR description.

## Issues

Not sure how to add something? Open an issue with the name, link and a one-line pitch, and a maintainer will help.
