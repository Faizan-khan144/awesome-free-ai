Most "AI tool" lists are bloated with paid products and dead links. This one focuses on **free and open-source** software you can run, self-host, or call through a free tier — chat UIs, coding agents, runtimes, image/audio models, vector databases and more. Every entry links to the real project. Star counts are approximate and there to signal maturity, not a ranking.

## Chat Assistants

- **[open-webui/open-webui](https://github.com/open-webui/open-webui)** `⭐ 156k` — Feature-rich, self-hosted web UI that works with Ollama and any OpenAI-compatible API.
- **[ChatGPTNextWeb/NextChat](https://github.com/ChatGPTNextWeb/NextChat)** `⭐ 89k` — Zero-config chat client for web and desktop with support for 100+ models.
- **[lobehub/lobehub](https://github.com/lobehub/lobehub)** `⭐ 83k` — Agent-centric workspace with a polished UI for chatting, plugins and teams of agents.
- **[mudler/LocalAI](https://github.com/mudler/LocalAI)** `⭐ 50k` — Drop-in, self-hosted OpenAI replacement: run LLMs, vision, voice and image models on any hardware.
- **[oobabooga/textgen](https://github.com/oobabooga/textgen)** `⭐ 48k` — Desktop app for local LLMs with text, vision, tool-calling and an OpenAI-compatible API.
- **[janhq/jan](https://github.com/janhq/jan)** `⭐ 45k` — Offline, open-source ChatGPT alternative that runs entirely on your machine.
- **[huggingface/chat-ui](https://github.com/huggingface/chat-ui)** `⭐ 11k` — The open-source chat interface that powers HuggingChat.

## Coding Assistants

- **[OpenHands/OpenHands](https://github.com/OpenHands/OpenHands)** `⭐ 91k` — Agentic developer environment that can write, run and debug code.
- **[cline/cline](https://github.com/cline/cline)** `⭐ 70k` — Autonomous coding agent available as an SDK, IDE extension or CLI.
- **[AntonOsika/gpt-engineer](https://github.com/AntonOsika/gpt-engineer)** `⭐ 55k` — CLI to experiment with code generation straight from a prompt.
- **[Aider-AI/aider](https://github.com/Aider-AI/aider)** `⭐ 50k` — AI pair programming in your terminal that edits your repo directly.
- **[continuedev/continue](https://github.com/continuedev/continue)** `⭐ 36k` — Open-source coding agent you can plug into your editor.
- **[voideditor/void](https://github.com/voideditor/void)** `⭐ 29k` — Open-source AI-native code editor (a Cursor alternative).

## Local Inference and Runtimes

- **[ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp)** `⭐ 131k` — LLM inference in pure C/C++ with almost no dependencies.
- **[vllm-project/vllm](https://github.com/vllm-project/vllm)** `⭐ 94k` — High-throughput, memory-efficient serving engine for LLMs.
- **[mozilla-ai/llamafile](https://github.com/mozilla-ai/llamafile)** `⭐ 26k` — Distribute and run LLMs with a single executable file.

## Free AI APIs and Platforms

Hosted services with a **free tier** or **free and open models** — great for prototyping without a bill.

- **[Groq](https://groq.com)** — Ultra-fast inference on open models with a generous free tier.
- **[OpenRouter](https://openrouter.ai)** — One API for hundreds of models, many of them free.
- **[Hugging Face](https://huggingface.co)** — Models, datasets, Spaces and a free Inference API.
- **[Google AI Studio](https://ai.google.dev)** — Free access to Gemini models and an API key in a click.
- **[Together AI](https://www.together.ai)** — Open-model inference with a free starter tier.
- **[Cohere](https://cohere.com)** — Free trial tier for chat, embeddings and rerank.
- **[Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/)** — Run models at the edge with a free daily allowance.
- **[Replicate](https://replicate.com)** — Run thousands of community models through a simple API.
- **[fal.ai](https://fal.ai)** — Fast inference for image, video and audio models.
- **[Mistral](https://mistral.ai)** — Open-weight models with a free API tier.
